# Site Inova Sorriso

Versão organizada do arquivo original, pronta para hospedagem estática no GitHub Pages.

## Estrutura

- `index.html`: conteúdo e estrutura da página
- `styles.css`: estilos visuais e responsivos
- `assets/images/`: imagens usadas pela página
- `.nojekyll`: evita processamento desnecessário pelo Jekyll no GitHub Pages

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie **todo o conteúdo desta pasta**, mantendo a mesma estrutura.
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/ (root)` e clique em **Save**.

O arquivo precisa se chamar `index.html` e ficar na raiz publicada, como já está nesta pasta.

## Testar localmente

Abra `index.html` no navegador ou execute um servidor HTTP local dentro desta pasta.
